# Historical Test Reports

Files already committed in this directory are dated snapshots from earlier
project stages. They do not describe committed v2 status.

- `metrics-report-2025-08-01_15-55-27.txt` predates the v2 ML, observability,
  contract, and expanded frontend suites. Its “all tests passed” statement is
  true only for the commands and code present in that 2025 run.
- `Usability Testing Data.xlsx` is a historical user-testing artifact, not an
  executable verification report or current capability specification.
- Newly generated reports should include the commit SHA, timestamp, exact
  command, runtime versions, exit status, passed/failed/skipped counts, and any
  missing prerequisites.

- `docs/TESTING.md`
- `docs/EVALUATION_STRATEGY.md`
- `docs/V2_UPGRADE_ANALYSIS.md`
